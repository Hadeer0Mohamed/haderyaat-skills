## 1. Grammar markers (the subtle leaks)

These give Egyptian away even when every word looks fine.

### Demonstratives
| Egyptian | Saudi |
|---|---|
| ده | هذا |
| دي | هذي / هذه |
| دول | هذولا / هذول |
| الراجل ده | هالرجال / هذا الرجال |
| الحاجة دي | هالشي / هذا الشي |

Note: Egyptian puts the demonstrative *after* the noun (الكتاب ده). Saudi puts it *before* (هذا الكتاب) or uses the هـ prefix (هالكتاب).

### Future tense
Egyptian uses هـ / حـ: هروح، هنعمل، حتشوف.
Saudi uses بـ (with future meaning) or راح / بـ + verb:
- هروح → بروح / راح أروح
- هنعمل → بنسوي / راح نسوي
- هتشوف → بتشوف / راح تشوف

### Present continuous
Egyptian بيعمل، بتقول (habitual/continuous بـ).
Saudi: plain imperfect or قاعد:
- بيشتغل → يشتغل / قاعد يشتغل
- بتعمل إيه؟ → وش تسوي؟ / وش قاعد تسوي؟
- إحنا بنحب → حنا نحب / احنا نحب

### Plural verb endings
Egyptian drops the نون: بيقولوا، عايزين يروحوا، انتو بتعملوا.
Saudi keeps it: يقولون، يبون يروحون، انتم تسوون.
- هم بيلعبوا → هم يلعبون
- انتو عايزين إيه؟ → وش تبون؟ / إيش تبغون؟
- (Past tense ـوا is fine in both: راحوا، سووا.)

### Negation
| Egyptian | Saudi |
|---|---|
| مش عارف | ما أدري / ما أعرف |
| مش كويس | مو زين |
| ماعملتش (ـش suffix) | ما سويت |
| مفيش | ما فيه / مافي |
| مش هقدر | ما راح أقدر / ما أقدر |

Never use the ـش negation suffix.

### Possession
بتاع / بتاعة / بتوع → حق / حقت / حقين — or just the possessive suffix:
- العربية بتاعتي → سيارتي / السيارة حقتي
- الملف بتاع الشغل → ملف الشغل

### Question words
| Egyptian | Saudi |
|---|---|
| إيه | وش / إيش |
| إزاي | كيف / شلون |
| فين | وين |
| ليه | ليش |
| إمتى | متى |
| مين | مين / منو (مين is fine in Saudi) |
| كام | كم |
| أنهي | أي / أيّ واحد |

## 4. Words that are fine in both (don't "fix" these)
عشان، بس، يعني، خلاص، تمام، طيب، يلا، مين، شنطة، زعلان، مبسوط، احنا، كويس (understood, though زين is more Saudi), صح، والله، الحمد لله، إن شاء الله، ماشي (acceptable but أبشر/تمام sounds more Saudi).

## 5. Before / after examples

**Input (Egyptian):**
لو انت عايز تعرف إزاي تحجز، ادخل على التطبيق دلوقتي واختار الخدمة اللي انت محتاجها، وهنكلمك في أسرع وقت.
**Output (Saudi):**
إذا تبغى تعرف كيف تحجز، ادخل التطبيق الحين واختار الخدمة اللي تحتاجها، وبنتواصل معك بأسرع وقت.

**Input (Egyptian):**
الحاجات دي مش هتلاقيها في أي حتة تانية، العرض ده لفترة محدودة أوي!
**Output (Saudi):**
هالأشياء ما راح تلقاها بأي مكان ثاني، والعرض لفترة محدودة مرة!

**Input (MSA):**
نعتذر عن التأخير، سيتم إرسال طلبك خلال ساعتين.
**Output (Saudi):**
نعتذر عن التأخير، طلبك بيوصلك خلال ساعتين.

**Input (Egyptian, casual):**
إيه يا جدعان، انتو فين؟ أنا مستنيكم من بدري ومحدش بيرد!
**Output (Saudi):**
وش فيكم يا جماعة، وينكم؟ أنا أنتظركم من بدري ومحد يرد!

**Input (i18n JSON):**
```json
{ "welcome": "أهلاً {name}، عامل إيه النهارده؟", "empty": "مفيش طلبات لسه" }
```
**Output:**
```json
{ "welcome": "هلا {name}، كيفك اليوم؟", "empty": "ما فيه طلبات للحين" }
```
